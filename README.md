# AI-Powered Recruitment and Resume Screening Assistant

## Project Overview

This project focuses on using Artificial Intelligence to improve the HR recruitment and resume screening process. It consists of three tasks that demonstrate AI-based research, a customised HR assistant and an Android application prototype.

## Assignment 1 – Research Using NotebookLM

This task involves researching the role of AI in recruitment and resume screening using NotebookLM. It helps understand recruitment challenges, AI applications, benefits, limitations and ethical considerations in HR management.

**Tool Used:** Google NotebookLM

## Assignment 2 – Custom Business Assistant Using Gemini Gems

This task involves creating a customised AI assistant called **AI Recruitment Assistant** using Gemini Gems. It supports HR activities such as preparing job descriptions, candidate screening guidance, shortlisting support and interview question generation.

**Tool Used:** Google Gemini Gems

## Assignment 3 – Android Business Application Using Google AI Studio

This task involves developing an Android application prototype called **HR RecruitPro**. The application provides features for candidate information entry, candidate management, sample skill matching and recruitment reports through a simple and user-friendly interface.

**Tool Used:** Google AI Studio

## Project Objectives

- Understand the use of AI in Human Resource Management.
- Identify challenges in manual recruitment and resume screening.
- Develop a customised AI assistant for HR activities.
- Build an Android application prototype for recruitment support.
- Demonstrate how AI tools can make recruitment more organised and efficient.

## Expected Outcome

The project demonstrates how AI-powered research, customised assistants and application prototypes can support HR recruitment activities, reduce manual effort and improve recruitment management.

## Technologies and Tools Used

- Google NotebookLM
- Google Gemini Gems
- Google AI Studio
